## 〇、一分钟看懂

```
微信好友/群 ──► 鲸鲸（收发）──► 本机桥接程序 ──► DSH（真正的脑子）──► 回复原路返回
```

- **鲸鲸**继续干她最擅长的：收发微信、发图、管账号。

- **桥接**是中间那根管子，在你本机 `127.0.0.1` 上，不出网。

需要装两个东西：

| 装什么 | 装到哪 | 命令 |
|---|---|---|
| 鲸鲸插件（写信封） | `I:\Whale-Girl\WhaleGirl\data\plugins\` | `npm run install:whale -- --apply` |
| DSH 设置页插件（配人格） | 你的 DSH profile | 见第四节（**未验证**） |

## 二、装鲸鲸插件

```powershell
npm run install:whale -- --apply
```

它会做三件事，只做这三件：

1. 确认目标目录真是鲸鲸（认 `package.json` + `src/services/messagePlugins.js`，不是就拒绝退出）
2. 如果有同名旧文件，先备份到 `.backup-<时间戳>/`
3. 写入 `whale-dsh-router.flow.json` + `whale-dsh-router.flow-grant.json`

**然后重启鲸鲸。**

### 怎么确认装上了

插件目录里应该有这两个文件：

```powershell
dir "I:\Whale-Girl\WhaleGirl\data\plugins\"
```

鲸鲸启动后，问她任何一句话，桥接日志里出现带信封的请求就说明生效了（见第三节）。

### 撤回

```powershell
npm run install:whale -- --uninstall --apply
```

删掉那两个文件，重启鲸鲸，恢复原样。

## 三、启动桥接 + 接到鲸鲸

### 1. 启动

```powershell
npm start
```

输出长这样（**每次的端口和令牌都不一样**）：

```json
{
  "listening": "http://127.0.0.1:57321",
  "token": "d48b3f0a…（48 位十六进制）",
  "adapter": "mock"
}
```

- 默认 `adapter: mock` = 回声后端，**不会真的思考**，只用来验证管子通不通。
- 要接真正的 DSH，见第 3 小节。

### 2. 填进鲸鲸

在鲸鲸的模型/API 配置里：

| 鲸鲸界面上的栏目 | 填什么 | 为什么 |
|---|---|---|
| 地址 / baseUrl | `http://127.0.0.1:57321`（**原样，不要加 `/v1`**） | 她会自己补 `/chat/completions` |
| Key / apiKey | `token` 那一整串 | **必须填**。空着的话她根本不发 `Authorization` 头，桥接直接 401 |
| 模型名 | 随便填，比如 `dsh` | 桥接不看这个名字 |

> 界面字段名以你看到的为准，我是按功能描述的。

### 3. 接真正的 DSH（而不是回声）

需要三个环境变量，缺一不可：

```powershell
$env:WHALE_BRIDGE_ADAPTER = 'acp'
$env:WHALE_BRIDGE_DSH_HOME = 'I:\DSH-Data\dsh-bridge-home'   # 必须是新目录，桥接会拒绝日常目录
$env:WHALE_BRIDGE_DSH_LAUNCHER = 'I:\DeepSeek Harness桌面端\DeepSeek Harness 官方端\resources\runtime\cli\bin'
npm start
```

- `DSH_HOME` 指向**一个全新的空目录**。桥接会检查，如果指向你日常的 `C:\Users\Administrator\.dsh` 或 `I:\DSH-Data\dsh`，直接拒绝。
- 那个新目录首次启动会自动建出 `profiles/acp`，**它用的模型要单独配**（见下面这条坑）。

> **坑**：ACP 会话用的模型配置在 profile 的 `cordis.patch.yml` 里的 `acp` 条目，**不是** `agent-default-model`。改错地方会一直报「no API key for provider route "deepseek-official"」，看着像没填 key，其实是没改到生效的位置。想用本地桩模型，抄 `tests/fixtures/isolated-acp.patch.yml`。

## 四、DSH 设置页（配人格）

> **未验证**：这个插件我没在你真实 DSH 里加载过。下面是照现有插件的挂载方式写的做法，第一次做之前务必先跑 `E:\桌面\DSH回档\` 存一份。

把 `plugin/` 目录挂进 DSH profile（以 desktop profile 为例）：

1. 用 junction 或复制，把 `whale-dsh-bridge\plugin` 放进 `I:\DSH-Data\dsh\profiles\desktop\node_modules\dsh-whale-bridge\`
2. 在 `profiles\desktop\package.json` 的 `dependencies` 里加 `"dsh-whale-bridge": "file:./node_modules/dsh-whale-bridge"`
3. 重启 DSH，设置里应该出现「鲸鲸桥接」一栏

**如果 DSH 起不来**：用 SAFE MODE（会先自动快照，再禁用除撤销工具外的所有用户插件），或者直接恢复回档。

## 五、人格怎么选

设置页「鲸鲸桥接」里有三档，**互斥**，选一档：

| 档位 | 什么效果 | 什么时候用 |
|---|---|---|
| **跟随 DSH** | 桥接什么都不注入，让 DSH 自己的 AGENT.md / soul 卡说话 | 你已经有满意的 DSH 人格 |
| **跟随鲸鲸** | 把鲸鲸请求里的 system 当首条背景传过去 | 想继续用鲸鲸那套人格页 |
| **自定义** | 用下面 10 个栏位拼出来 | 想自己捏一个 |

### 自定义那 10 栏

分组是：核心（身份与动机 / 说话方式 / 口头习惯）、情绪（生气 / 难过 / 高兴 / 被冒犯）、关系与边界（怎么看对方 / 绝不做的 / 场景差异）。

只有 **「身份与动机」** 必填。每栏输入框里都有灰色示例铺底，照着写就行。

**写的时候记住一件事**：这段文字会作为会话第一条留在上下文里，之后**每一轮都会跟着重发**。设置页上直接写着每轮多少 token、100 轮累计多少。

- 300 字 ≈ 330 token/轮
- 1200 字（上限）≈ 1320 token/轮，100 轮约 13 万

**写多了不会更聪明，只会更慢更贵。** 超预算时系统会整块丢弃（先丢场景、再看对方，最后才动「渴望」和「红线」），不会切半句。

### 示例（身份与动机）

不要写「一个温柔的电台主播，25 岁」，写他此刻在渴望什么：

> 我每晚在电台念陌生人的留言，却一直想知道那个从不留言、只听的人是谁。

## 六、记忆

### 它记得什么

三层，各干各的：

| 层 | 内容 | 什么时候进上下文 | 上限 |
|---|---|---|---|
| 人格层 | 你是谁的提炼（「我怕黑」「我喜欢吃辣」） | 每轮 | 320 字 |
| 情节层 | 这个会话的对话原文，**不压缩** | 平时不进，你提到旧事才进 | — |
| 跨会话 | 别的会话里标为「可外传」的 | 命中 + 你提到旧事才进 | 420 字 |

整块硬上限 700 字。

### 隔天再聊还记不记得

能。新会话第一条会自动带上：

```
上次和这个人聊到（这是真的记录，不是你编的）：
· 我最近在准备一场很重要的面试
· 面试在下周三
【别假装记得细节，不确定就别提。】
```

只取你（用户）说的、最近 3 条、硬截 200 字。**只在会话开头一次**，不是每轮。

### 什么能跨会话、什么不能

- 关于「它自己」的 → 可外传（「我喜欢吃辣」）
- 别人告诉它的 → 永久私密（「他说…」「别告诉别人」）
- 判断不了的 → 默认私密

### 让它长大

设置页「记忆」区块里有「整理人格层」按钮，或者：

```powershell
npm run grow
```

它扫所有会话，只挑第一人称的自我陈述，去重后硬截 320 字。**纯规则，不花 token**。

建议**偶尔跑**（每天一次或聊了一批再跑），不要每轮跑。

### 主动开话题（做不到）

桥接是响应式的：鲸鲸推过来才回。素材侧备好了（能挑出「问过没答案」「说了改天没兑现」的事），但**没有主动发起的入口**——那要接到鲸鲸的关怀流程，属于改她的主程序，得单独授权。

## 七、自检

```powershell
npm run selfcheck
```

27 项，只查本地，不连网、不启动任何东西。

- **全过**：一声不响，退出码 0。
- **有失败**：弹窗列出失败项，同时写 `logs/selfcheck-<时间戳>.log`，只留最近 20 份。
- 脚本里跑加了 `--quiet` 就不弹窗。

## 八、排错对照

| 现象 | 大概原因 | 怎么办 |
|---|---|---|
| 鲸鲸报「空响应」 | 代理没回 SSE | 已修；还出现就查版本 |
| 401 / 未授权 | Key 栏空着或填错 | 把 `token` 原文填进 Key |
| 503 `no_upstream` | 请求里没信封 = 插件没生效 | 查 `data\plugins` 那两个文件在不在、鲸鲸重启没 |
| 插件装了没反应 | 文件放错位置或授权 hash 不对 | 跑 `npm run make:flow` 重新生成，再装一次 |
| 改了人格语气没变 | 人格变更会开新会话 | 正常；记忆不会丢（已按会话分桶） |
| 改人格后记忆没了 | 旧版本的 bug | 已修 |
| DSH 起不来 | 设置页插件挂错 | SAFE MODE，或恢复回档 |
| 跑完探针进程没退 | 旧版本没杀进程树 | 已修；还出现就 `taskkill /F /T /PID` |

## 十、三条安全提醒

1. **不要把这个桥接挂到你正在跑的 DSH 上**，除非先跑 `E:\桌面\DSH回档\` 存一份。
2. **令牌不要外传**。它等于「谁都能让这台机器跑一轮 DSH」。
3. **外部聊天进来的人不能操作这台机器**：工具白名单恒为空、权限请求一律拒绝，这是代码里写死的，不是配置项。

另外说清楚：**上架、源码公开、自动检查、人工审核或文件校验，都不能保证插件没有病毒、恶意行为或漏洞。** 这个插件的源码就在 `whale-dsh-bridge\` 里，装之前自己翻一遍 `whale-dsh-router.flow.json` 的 `permissions` 字段——只有 `model.prompt`，没有 `chat.history`。
