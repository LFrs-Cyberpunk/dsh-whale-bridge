### 额外做出来的（超出原目标）

- **三层记忆**：人格层（≤320 字，每轮）/ 情节层（按会话存原文，不压缩，平时不注入）/ 跨会话（只读 `shareable`，回溯信号才注入，≤420 字）。整块硬上限 700 字。
- **隐私分级**：关于「我」的可外传；别人告诉我的永久私密；判断不了默认私密。
- **人格层成长**：`npm run grow` 或设置页按钮，纯规则零 token，只收第一人称陈述。
- **风格统计**：句长/短句率/标点/表情比例两行摘要，绝不注入他人原句。
- **自检失败弹窗**（用户早就要求过的那条）。

### 隔天重聊还记不记得

这是用户直接问过的，单独说清楚——之前只算半个能。

| 场景 | 结果 |
|---|---|
| 隔天说「上次那个面试怎么样了」 | 能查到原话（检索命中，标注「你记得的事」） |
| 隔天只说「今天好累」 | **补上了**：新会话首条自动带「上次和这个人聊到」摘要 |
| 改一次人设 | **补上了**：记忆按会话分桶，不再跟着人格版本号走 |

开场摘要只取用户说的、最近 3 条、硬截 200 字，并明确写「不确定就别提」——宁可不说，也不编。

### 主动开新话题（做不到，如实说）

桥接是响应式的：鲸鲸推消息过来我们才回，**没有主动发起的入口**。素材侧已经备好（`openTopics()` 能挑出「问过没答案」「说了改天没兑现」的事，最多 3 条 160 字，闲聊不算），但要真发出去，需要接到鲸鲸的关怀/提醒流程——那属于改她的主程序，是红线，要你单独授权。

## 三、关键发现（都推翻了之前的假设）

### 1. 鲸鲸运行时**不读 `plugin.json`**

`messagePlugins.js:121-136` 只扫 `<dataDir>/plugins` 下的 `<id>.flow.json` + `<id>.flow-grant.json`，整个 `src` 里没有 ZIP 解压器。之前打的两个 ZIP **装了也没用**。

已按正确格式产出：`npm run make:flow` → `whale-dsh-router.flow.json` + `.flow-grant.json`。

### 2. 4.1.2 的 JS 插件运行时也发不出网络

`pluginHost.js:26` 只暴露 `api/capabilities/search/model/send/delivery` 六种能力，且 `api` 被钉死在插件自己的基址（`new URL(args.url, runtime.pluginApiUrl)`）。**绕不过桥接**。

顺带：WASM 的权限校验一行没改（`messagePlugins.js:130` 仍只认 `chat.history` / `model.prompt`），且**没有开关**——不像 JS 插件要开实验总开关。所以我们的方案权限最轻、最省事。

### 3. ACP 会话的模型配置在 `acp` 条目

不在 `agent-default-model`。改错地方会一直报「no API key for provider route "deepseek-official"」，看起来像凭据问题。

### 4. 杀 `cmd.exe` 不杀它启动的 Electron 子进程

探针必须进程树 kill（`taskkill /F /T /PID`），否则残留宿主锁住隔离 HOME。

## 五、没做的 / 不能保证的

### 需要你决定的三件事

1. **放进鲸鲸**：`npm run install:whale -- --apply`，然后重启鲸鲸看插件是否被认出。只写两个文件，撤回一条命令。**这是整条链路最后一块没验的拼图。**
2. **真模型回复质量**：隔离宿主现在接的是本地桩。要验真实回复，需要一个能用的 key——只动 `.test-home`，不碰日常。
3. **设置页挂进日常 DSH**：要重启，快照已备好。

### 明确不能保证的

- 设置页没在真实 DSH 里加载过（只证明了 bundle 可加载、注册契约与两个已工作插件一致）。
- 真实微信消息流没经过本桥。
- 「学会说话」做不到——插件无法微调模型，只能做风格统计。
- 人格层的自动成长需要手动触发，不会自己长大。

### 已知接口缺口（如实报告）

1. 鲸鲸 `buildPayload` 不带 chatId/senderId，必须靠插件写信封。
2. 后台/记忆提取请求不带信封 → 只能透传或明确拒绝。
3. `state.seq` 重启归零 → `messageId` 复用会退化成陈旧回答。
4. ACP 没有 system prompt / 人设通道，人设只能作首条消息背景——**它按轮计费**。

## 七、第三方插件的风险声明

- 本项目自写的两个插件（DSH 设置页、鲸鲸信封路由）源码都在 `whale-dsh-bridge/` 内，可直接审阅。
- **上架、源码公开、自动检查、人工审核或文件校验，均不能保证插件没有病毒、恶意行为或漏洞。**
- 信封**故意不签名**：ZIP 要公开，内置密钥等于公开密钥。信封只声称「这是哪个会话」，绝不承担「这个人有什么权限」——权限由 engine 硬编码。
- 装进鲸鲸之前，建议先看一遍 `whale-dsh-router.flow.json` 的 `permissions` 字段：只有 `model.prompt`，没有 `chat.history`。
