# 使用手册 · whale-dsh-bridge v1.0.0`n`n> 对外版本 1.0.0。这份只讲手怎么动，不讲原理。

这份不讲原理，只讲**手怎么动**。每一步都写「你应该看见什么」，看见了就往下走，没看见就翻第四部分对表。

> 装的是**新版 JS 插件**（Api 4）。它的好处是鲸鲸不再自己生成回复，直接把你本机的 DSH 答案发出去——**不花两份钱，上下文也不会每次清空**。

# 第一部分：装一次（大约 10 分钟）

## 第 1 步　打包出一个安装包

1. 按 `Win` 键，输入 `powershell`，回车，开一个蓝窗口
2. 复制下面这一整段（三行，一起粘），回车：

```
cd "I:\DeepSeek Harness工作区\程序开发\whale-dsh-bridge"
npm run pack:js
dir whale-plugin\dist\*.zip
```

**你应该看见：**

```
"file": "...\whale-plugin\dist\whale-dsh-bridge-1.0.0.zip",
"entries": ["plugin.json", "plugin.js"],
"sha256": "65a87f56...",
```

以及最后一行列出这个 zip 文件。

**记住这个路径**：`I:\DeepSeek Harness工作区\程序开发\whale-dsh-bridge\whale-plugin\dist\whale-dsh-bridge-1.0.0.zip`

## 第 2 步　打开 JavaScript 实验总开关

1. 打开鲸鲸 → **插件市场**
2. 找到「**启用 JavaScript 插件（实验性）**」这个开关，打开
3. 它会警告你：这类插件能用网络、文件、系统命令和全部主程序 API

**如果你接受，继续。** 不接受就停在这里，回退用老方案。

## 第 3 步　从本地安装这个 ZIP

1. 还在插件市场页
2. 点「**从本地安装**」
3. 选中第 1 步那个 zip
4. 确认框会显示：`DSH 桥接` / `message` / 扩展点 `chat.generate` / 权限 `system.full`

**核对三样**：名字对、类型是 message、权限只有 `system.full`。对就装。

## 第 4 步　启用并授权

1. 切到「**已安装**」，找到「DSH 桥接」
2. 点「**启用**」
3. 它会要求确认**完整系统权限** —— 看清楚，同意

> 这个权限意思是：这段代码能在你电脑上做任何事。代码只有 5.7KB，路径 `whale-dsh-bridge\whale-plugin\js\plugin.js`，就一个功能：把消息 POST 到 `127.0.0.1`，把答案拿回来。你可以自己打开看。

## 第 5 步　把桥接装进 DSH 设置页（只做一次）

做完这一步，以后**不用再开蓝窗口**——桥接由 DSH 插件自己管，你只需在设置页点一个开关。

**这一步我没在你机器上验证过。** 做之前先跑一次 `E:\桌面\DSH回档\`。

1. 用记事本打开 `I:\DSH-Data\dsh\profiles\desktop\package.json`
2. 找到 `"dependencies"` 那一段，在它的大括号里加一行（注意上一行末尾要有逗号）：

```json
"dsh-whale-bridge": "file:I:/DeepSeek Harness工作区/程序开发/whale-dsh-bridge"
```

3. 保存，**重启 DSH**
4. 打开 DSH 设置，左侧应该多出一栏「**鲸鲸桥接**」

**没出现**：挂载没成功，把 DSH 启动时的报错发我。

## 第 6 步　在设置页打开开关

进 DSH → 设置 → 鲸鲸桥接。最上面一块是「**桥接服务**」：

```
● 桥接服务                     [开启]
已停止 · 停止时微信那边会收不到回复
超时（毫秒）  [40000]  [保存]
地址和令牌由桥接自动写入鲸鲸插件，不用手填。
```

点「**开启**」。

**你应该看见：**

- 圆点变绿
- 文字变成「运行中 · http://127.0.0.1:xxxxx」

**这样桥接就通了。** 它在后台跑，地址和令牌会自动写进鲸鲸插件——**你一个字符都不用填**。

> 桥接是**独立进程**，不跑在 DSH 里面。它崩了可以自己重启，不会把 DSH 带下去。连续崩 3 次会自己停下，不会无限重拉。

## 第 7 步　试一条

在微信找个小号发一条消息。

**你应该看见**：微信收到回复。

收到固定的假回复（「这是测试回复」之类）= 还在 mock 模式，看第二部分第 3 节接 ACP。

# 第二部分：平时怎么用

## 1. 每天开机要做的事：没有

**桥接跟着 DSH 走。** 你打开 DSH，插件就起来了；DSH 关掉，桥接也跟着停。

如果你在设置里把开关关掉了，再打开 DSH 后需要**手动再点一次开启**。

**令牌不会变**（存在 `.test-home\bridge-token.txt`），**地址和令牌会自动更新进鲸鲸插件**，所以你永远不用手填。

## 2. 在鲸鲸里平时做什么

**什么都不用做。** 装好之后正常聊天。

你只需要管这几个地方：

| 想干什么 | 去哪 |
|---|---|
| 让 DSH 回答 / 让鲸鲸自己回答 | DSH 设置页的桥接开关，或插件配置里的 `enabled` |
| 停用整个插件 | 插件市场 → 已安装 → 停用 |
| 改超时 | 插件配置里的 `timeoutMs` |

**插件配置文件在哪**：`I:\Whale-Girl\WhaleGirl\data\plugins\whale-dsh-bridge.data\config.json`

里面有四个值：

```json
{
  "enabled": true,          // 关掉 = 完全不接 DSH，全交回鲸鲸自己
  "url": "http://127.0.0.1:57321",   // 桥接地址，桥接启动时自动更新
  "token": "...",           // 桥接令牌，启动时自动更新
  "timeoutMs": 40000        // 等 DSH 多久算超时
}
```

**日常你只会动 `enabled`。** 改完保存，下一条消息就生效，不用重启。

## 3. 让它真的用 DSH 的脑子

默认是 **回声**（把你说的原样加个前缀，不会思考）。要让它真思考，**在设置页里改**，不用碰命令行。

进 DSH → 设置 → 鲸鲸桥接，找到「**回答用哪个**」：

```
回答用哪个   [本机 DSH（真思考） ▾]
```

选它之后会展开四个框：

| 框 | 填什么 |
|---|---|
| **API Key** | 你的模型 Key。**保存后不会再显示**，下次留空就是不修改 |
| **接口地址** | 默认 `https://api.deepseek.com`，用别的中转就改这里 |
| **模型** | `deepseek-flash`（快）或 `deepseek-pro`（强） |
| **推理等级** | `off` / `low` / `medium` / `high` |

填完点「**保存设置**」，然后**先点「关闭」再点「开启」**——改设置不会自动重启桥接。

**你应该看见**「模型配置已写入隔离宿主」。

### 为什么不能共用你日常 DSH 的 Key

你日常的模型是**会话级**选择：每个会话窗口各自选模型，token 记在对应会话头上。

桥接跑的是**另一个 DSH 进程**，它没有"当前会话"，**也就没有可继承的模型**。这不是没找对方法，是这个东西本身不存在。

所以这里要单独填一把 Key。它存在本机，只给隔离的那个 DSH 用。

### 三条要注意

1. 隔离宿主的数据目录在 `whale-dsh-bridge\.test-home\dsh\`，**第一次启动会慢十几秒**（要建目录）。
2. 它和你日常 DSH（`C:\Users\Administrator\.dsh`）**完全隔离**：没有人格、没有会话、没有插件。代码里写死了护栏，填日常目录会被拒绝。
3. 那个人格从哪来？走微信请求里带的自定义人格（设置页「人格来源」那一块）。

## 4. 在 DSH 里怎么操作

**先看清楚：你可能没有这一块。**

| 情况 | DSH 里能看到什么 |
|---|---|
| 只装了鲸鲸插件 | **什么都没有**。DSH 是被动干活的。人格用 DSH 自己的（AGENT.md + soul 卡） |
| 另外挂了「鲸鲸桥接」设置页 | 设置里多一栏「鲸鲸桥接」 |

**设置页怎么装**（这一步我没在你机器上验证过，第一次做之前先跑 `E:\桌面\DSH回档\`）：

1. 把 `whale-dsh-bridge\plugin` 目录复制到
   `I:\DSH-Data\dsh\profiles\desktop\node_modules\dsh-whale-bridge\`
2. 打开 `profiles\desktop\package.json`，在 `dependencies` 里加一行：
   `"dsh-whale-bridge": "file:./node_modules/dsh-whale-bridge"`
3. 重启 DSH

**装上之后能看到什么：**

| 那一栏里的块 | 能干什么 |
|---|---|
| 人格来源 | 三选一：跟随 DSH / 跟随鲸鲸 / 自定义 |
| 人格内容 | 选「自定义」才出现，10 个填空框，灰字提示写什么 |
| 记忆 | 几个会话、多少条，一个「整理人格层」按钮 |

**三个常用操作：**

- 换人格：`人格来源 → 选一档 →（自定义就填框）→ 保存人格`
- 看它记得什么：`记忆 → 上面那行字`
- 让它整理人格：`记忆 → 点「整理人格层」，等几秒`

**注意**：接 DSH 之后，微信那边的人格要在这里设；不装这个设置页，就永远是 DSH 自己那套。

# 第四部分：出问题了对这张表

| 你看到的 | 意思 | 怎么办 |
|---|---|---|
| 回复是固定的假话（「这是测试回复」） | 还在 mock 模式 | 按第二部分第 3 节接 ACP |
| 插件装好了但没反应 | 总开关没开 / 没启用 / 没授权 | 回插件市场逐个检查 |
| 微信没收到回复 | 桥接挂了，插件降级成鲸鲸自己答 | 看蓝窗口在不在 |
| 蓝窗口报 401 | 令牌不对 | 重启桥接，它会自动重写插件配置 |
| 蓝窗口报 `no_upstream` | 请求里没信封 | 插件版本不对，重装第 1 步打的包 |
| 等很久才回 / 不回 | DSH 那边慢或卡 | 看蓝窗口；`timeoutMs` 调大写 |
| 鲸鲸启动报插件加载失败 | 包不对 | 确认 zip 根目录只有那两个文件 |
| DSH 起不来 | 设置页挂错 | SAFE MODE，或恢复回档 |
| 电脑很卡 | 桥接+鲸鲸+DSH 都在跑 | 正常 |

**万能操作**：把蓝窗口里的字**整段复制**发给我。

# 第五部分：撤掉

| 撤什么 | 怎么做 |
|---|---|
| 临时停用 | 插件配置里 `enabled` 改 `false`，或插件市场点「停用」 |
| 卸载插件 | 插件市场 → 已安装 → 卸载（会连数据目录一起删） |
| 关掉 JS 实验开关 | 插件市场 → 关掉那个总开关（所有 JS 插件都停） |
| 撤 DSH 设置页 | `E:\桌面\DSH回档\` 恢复 |

# 第六部分：给别人用，交代这四句

1. **这不是微信外挂**。改的是你这台机器上的鲸鲸，微信里看到的就是她本人。
2. **消息会经过你本机的 DSH 处理**，记录存在本机，不上传。
3. **桥接开着才回消息**。电脑关了、窗口关了，她就不回。
4. **插件不等于安全**：上架、校验、扫描、审核都不保证无病毒无漏洞。这个插件权限是 `system.full`（完整系统权限），代码在 `whale-dsh-bridge\whale-plugin\js\plugin.js`，自己看一遍再装。
